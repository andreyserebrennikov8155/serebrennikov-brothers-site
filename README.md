# The Serebrennikov Brothers — сайт

Простой статический сайт-визитка для продуктов братьев Серебренниковых.

## Структура

- `index.html` — главная страница (О нас, Продукты, Планы, Контакты)
- `privacy.html` — шаблон политики конфиденциальности (нужно заполнить реальными данными)
- `support.html` — страница поддержки/контактов (нужно заполнить реальными данными)
- `assets/css/style.css` — стили
- `assets/js/main.js` — небольшой JS (год в подвале, мобильное меню)
- `assets/img/` — изображения и скриншоты

## Что заменить перед публикацией

1. Реальные ссылки на RuStore/Google Play в карточках продуктов.
2. Реальный email/контакты в `index.html`, `privacy.html`, `support.html`.
3. Текст политики конфиденциальности под конкретные приложения и дату обновления.
4. При желании — логотип/скриншоты в `assets/img/`.

Обновлено: ссылка на личный сайт Андрея добавлена — https://andreyserebrennikov8155.github.io/andreyserebrennikov-site/

## Локальный просмотр

Откройте `index.html` в браузере. Сервер не обязателен.
